# AG-VLA Finetuning
## Description
The finetuning script performs end-to-end training for the full AG-VLA architecture (OmniVLA -> action projector -> action head) so that the VLA backbone is better aligned with the original action projector and action head. It uses custom made navigation data for the AION robot in a agricultural environment. The script is designed to be ran in Spartan (provide link, what is Spartan?).
